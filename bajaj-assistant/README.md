# Bajaj Finserv Loan + Fund Cross-Sell Assistant

An AI assistant that answers loan customer queries and recommends Bajaj Finserv mutual funds based on cross-sell propensity.

## Setup

```bash
python -m venv venv
# venv\Scripts\activate   (Windows)
# source venv/bin/activate  (macOS/Linux)
pip install -r requirements.txt
```
